Changelog

What changed in each mwitch release. Installed copies pick these up automatically via Sparkle; you can also browse releases on GitHub.

1.0.1

August 11, 2026
  • mwitch is out of alpha. First stable release.
  • Display-friendly switching. Switching to a window no longer disturbs your other display: mwitch raises only the window you picked, instead of first fronting the app's previous key window over whatever you had on the other screen.
  • Hardened filtering of native tab surfaces (Ghostty, Terminal): background tabs are told apart from real windows by WindowServer Space membership, so two same-sized windows no longer collapse into one row.
  • True per-window most-recently-used ordering, seeded at startup so the list is correct from the first Cmd+Tab.
  • Includes the 0.3.7 recency fix below, which was tagged but never shipped.

0.3.7

June 23, 2026 · unpublished
  • Fixed per-window recency tracking for apps that only report app-level Accessibility events, so the most-recently-used order stays accurate. Shipped in 1.0.1.

0.3.6

June 17, 2026
  • Most-recently-used ordering. The switcher lists windows in the order you last used them instead of app z-order.

0.3.5

June 15, 2026
  • Windows on other Spaces that Accessibility can't map (e.g. Discord) show up in the switcher again.

0.3.4

June 12, 2026
  • Fixed switching to windows of hidden apps.

0.3.3

June 9, 2026
  • Esc now cancels the switcher on every install: cancel is handled from the global event tap instead of the panel.

0.3.2

June 3, 2026
  • Show windows whose window-list title is empty (e.g. Contacts).
  • The update check shows the version only, without the build number.
  • Site: copy button for the Homebrew install command.

0.3.1

May 31, 2026
  • Clearer message when an update check finds no new version.

0.3.0

May 31, 2026
  • Simplified the status menu: removed the Show Switcher, Accessibility Settings, and Screen Recording Settings items.

0.2.2

May 31, 2026
  • Rewrote the switcher panel in SwiftUI and separated UI presentation from session state.
  • Fixed a commit-gating bug where releasing unrelated modifiers could commit the switch.

0.2.1

May 30, 2026
  • First public release, published via GitHub Releases.
  • Sparkle auto-update.
  • Search results ranked by match quality, with a fix for a search/selection state conflict.
  • Windows matched by CGWindowID so switching works in Chrome.
